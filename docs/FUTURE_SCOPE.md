# Future Scope & Technical Roadmap

The MVP of Scam Tactic Detector establishes a robust foundation for explainable linguistic threat detection. The following roadmap outlines strategic enhancements for production scale.

---

## 1. Multimodal Audio & OCR Ingestion
- **Voice Scam Telemetry:** Integrating speech-to-text (Whisper API / on-device Vosk) to transcribe incoming voice calls from suspected fraudsters in real-time.
- **Image / Screenshot OCR:** Using Tesseract or Vision Transformers to extract text from forged account balance screenshots, fake regulatory certificates, and transaction receipts.

---

## 2. Browser Extension & Mobile Keyboard Overlay
- **Chrome / Firefox Extension:** Real-time web chat monitor highlighting scam tactics directly within WhatsApp Web, Telegram Web, and Reddit DMs before the user replies.
- **Privacy-Preserving Mobile Keyboard:** Client-side heuristic analyzer warning users as they type or paste text into financial messaging threads.

---

## 3. Multilingual Support
- Expanding detection engines beyond English to regional languages frequently targeted in cyber fraud (Hindi, Spanish, Portuguese, Bahasa, Tagalog).

---

## 4. Threat Intelligence & Community Reporting
- **Decentralized Red-Flag Registry:** Optional anonymous sharing of hashed suspicious phrases to catalog emergent threat campaigns and new linguistic patterns across the network.
- **Automated Regulatory Reporting:** One-click generation of standardized cybercrime complaint dossiers formatted for submission to cybercrime portals (e.g. India Cyber Crime Portal, US IC3).
